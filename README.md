# CS3IV
This coursework assignment aims to enhance your understanding of techniques used
for image enhancement in both spatial and frequency domains. 
Two images, DogOriginal.bmp and DogDistorted.bmp, used in this assignment can be downloaded
from the Blackboard site under: Assessment -> Technical report 1 -> Coursework
assignment: image enhancement

The original grey level image (DogOriginal.bmp) and distorted/noisy image
(DogDistorted.bmp) are shown in Figures 1(a) and 1(b), respectively. It is known that
the distortion is caused by a combination of periodic noise and random noise. You
are required

• to develop algorithms in both the frequency and spatial domains to improve
the quality of the distorted image by removing or reducing noise, and to
compare resulted images from different algorithms in discussion (refer to the
marking schemes in Section 5 for more detailed requirements); and

• to evaluate the results using the Mean Square Error (MSE) measure
